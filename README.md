# 暖像素乐坊 Warmpix Music

可演奏乐器与十二张原创唱片的 NeoForge 模组。

- Minecraft: 26.3
- Loader: NeoForge 26.3.0.23-beta 及以上
- 客户端与服务端都需要安装，无其他前置
- 语言：简体中文 / English

## 下载

请到 [Releases](../../releases) 页面下载 jar。

## 内容

- 18 种乐器，分四个档次（入门档可合成）
- 12 张原创唱片（约 96 秒/张）
- 多种乐器家具，支持录制乐谱与合奏
