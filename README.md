可演奏乐器与十二张原创唱片的 NeoForge 模组。

- Minecraft: 26.3
- Loader: NeoForge 26.3.0.23-beta 及以上
- 客户端与服务端都需要安装，无其他前置
- 语言：简体中文 / English
